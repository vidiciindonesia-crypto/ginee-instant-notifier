PENGUMUMAN PESANAN INSTAN - GINEE OMS

Untuk Windows 10/11 64-bit. Python tidak perlu dipasang.

1. Jalankan PengumumanPesananInstan.exe.
2. Buka Pengaturan API & layanan. Masukkan key Ginee sendiri dan simpan.
3. Klik Mulai / uji koneksi.
4. Klik Tes instan biasa dan Tes suara & pop-up.
5. Minimalkan aplikasi agar tetap memantau.

Untuk mencari pesanan di Ginee: pilih satu baris, klik Salin nomor pesanan,
atau tekan Ctrl+C ketika tabel aktif. Tempel hasilnya di kolom pencarian Ginee.

Suara wanita Indonesia sudah termasuk di EXE. Internet diperlukan untuk API Ginee.
Pesanan instan dapat berasal dari Shopee, TikTok, atau marketplace lain di Ginee.
Instan prioritas disebutkan khusus. Pengumuman tidak dibatasi aturan 15 menit.
Saat status Sedang Dikirim/SHIPPING tersinkron, suara dan pengingat pesanan
tersebut berhenti, termasuk suara yang masih antre atau sedang berjalan.
Perubahan status diperiksa mengikuti interval sinkronisasi (bawaan 30 detik).
Timer 15 menit hanya informasi lokal Shopee prioritas sejak pembayaran berhasil.

Kunci dan riwayat disimpan terpisah di akun Windows masing-masing PC.
File EXE tidak memuat key API, pengaturan akun, atau data pesanan.
Setiap PC mengisi key sendiri. Riwayat pengumuman antar-PC tidak disinkronkan.

Jika pesanan tidak muncul, pastikan status Terhubung, lalu gunakan Salin log.
Tutup aplikasi lama sebelum menjalankan versi baru.
